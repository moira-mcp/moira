На этой странице описаны системные инструкции, которые автоматически предоставляются AI агентам при подключении к серверу MCP Moira.

## Как доставляются инструкции

MCP Moira доставляет инструкции через поле MCP `instructions` при инициализации сервера.

Описания инструментов, включая варианты для агентов и моделей, входят в статический каталог. Они
никогда не содержат системный промпт текущей установки и не переопределяются через глобальные настройки.

Клиенты с OAuth- и API-токенами принимают текущий статический каталог во время MCP `initialize`.
Если обычный запрос получает HTTP 426 с `upgrade_required`, переподключитесь с теми же действующими
учётными данными, чтобы клиент снова выполнил инициализацию; менять токен для обновления каталога не
требуется.

## Источник истины

Версия по умолчанию хранится в `config/prompts/systemPrompt.md`. При запуске миграция помещает её в
базу runtime-настроек, где администратор может управлять поддерживаемыми переопределениями промпта
для агентов и моделей. Ниже показана сохранённая в репозитории версия по умолчанию, а не текущее
значение конкретной установки.

Источник по умолчанию:

- загружается в runtime-настройку, которая передаётся через поле MCP `instructions`;
- отображается на этой странице через соответствующую публичную копию.

Agentic Screencast Video превращает заявленную тему в готовую видеопрезентацию. Флоу фиксирует, что и кому должно показать видео, проверяет, что локальная среда умеет рендерить и озвучивать, и дальше ведёт работу по фактам, сценарию, материалам и озвучке, независимо проверяя каждый артефакт до того, как от него начнёт зависеть следующий.

```bash
mcp__moira__start({
  action: "prepare",
  workflowId: "moira/agentic-screencast-video",
  parentExecutionId: "none"
})
mcp__moira__start({ action: "execute", startAttemptId: "<Start attempt ID из prepare>" })
```

## Доказательства и процесс

Каждое утверждение, попадающее на экран, опирается на записанный источник: факты сначала собираются и проходят независимое ревью, и только потом пишется сценарий, а сценарий проверяется до съёмки материала. Сначала собирается бесплатный черновик, поэтому дорогие шаги — платный синтез речи, запись человеком, финальный рендер — начинаются с версии, которую ревьюер уже видел. У каждого ревью свой маршрут ремонта: дефект возвращается к вызвавшему его артефакту, а не в начало.

Озвучка — осознанный выбор: синтетический голос, запись человеком или немой вариант. Платный синтез не запускается без авторизации расходов пользователем.

## Полномочия

Коммит созданных файлов и передача готового MP4 — отдельные гейты разрешения: ни то ни другое не происходит только потому, что инструмент доступен. Флоу не публикует видео, ничего не разворачивает и не меняет продакшен.

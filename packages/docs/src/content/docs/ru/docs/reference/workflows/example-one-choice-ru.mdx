Учебный пример с одной развилкой: агент выполняет задачу и отвечает на один вопрос «да или нет» — полностью ли результат соответствует запросу? «Да» ведёт к отчёту, «нет» — к честному объяснению, чего не хватает. Без циклов и без переменных. Для настоящей работы опишите задачу своему агенту — он сам выберет готовый флоу или создаст новый.

## Шаги

- Выполните задачу, о которой просил пользователь.
- Проверьте результат по запросу. Ответьте yes, если он полностью совпадает, или no, если чего-то не хватает.
  - **да — совпадает** →
    - Расскажите пользователю в нескольких предложениях, что вы сделали.
  - **нет — чего-то не хватает** →
    - Расскажите пользователю, чего не хватает и почему, и предложите, что делать дальше. Не начинайте задачу заново в этом флоу.

## Как запустить

Проще всего попросить агента обычными словами, например:

> «Запусти пример Мойры „Пример 2: Одна развилка“ для этой задачи: …»

Агент, который вызывает инструменты напрямую, запускает его так:

```js
mcp__moira__start({ action: "prepare", workflowId: "moira/example-one-choice-ru", parentExecutionId: "none" })
mcp__moira__start({ action: "execute", startAttemptId: "<Start attempt ID from prepare>" })
```

Это учебный пример. Для настоящей работы не нужно выбирать или собирать флоу: опишите задачу своему агенту — он сам выберет готовый флоу или создаст новый.

Учебный пример с несколькими ветками: агент определяет, что пришло — вопрос, ошибка или новая идея, и каждый ответ ведёт по своему короткому пути. Без циклов и без переменных. Для настоящей работы опишите задачу своему агенту — он сам выберет готовый флоу или создаст новый.

## Шаги

- Прочитайте запрос пользователя и решите, что это: вопрос (question), ошибка, которую надо исправить (bug), или новая идея (idea).
  - **вопрос** →
    - Кратко ответьте на вопрос и укажите, откуда взят ответ.
  - **ошибка** →
    - Воспроизведите ошибку, исправьте её и покажите пользователю, что она больше не возникает.
  - **идея** →
    - Составьте короткий план идеи, не больше пяти шагов, и спросите пользователя, браться ли за неё.

## Как запустить

Проще всего попросить агента обычными словами, например:

> «Запусти пример Мойры „Пример 3: Несколько путей“ для этой задачи: …»

Агент, который вызывает инструменты напрямую, запускает его так:

```js
mcp__moira__start({ action: "prepare", workflowId: "moira/example-several-paths-ru", parentExecutionId: "none" })
mcp__moira__start({ action: "execute", startAttemptId: "<Start attempt ID from prepare>" })
```

Это учебный пример. Для настоящей работы не нужно выбирать или собирать флоу: опишите задачу своему агенту — он сам выберет готовый флоу или создаст новый.

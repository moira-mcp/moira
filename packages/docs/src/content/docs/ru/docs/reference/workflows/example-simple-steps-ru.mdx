Учебный пример для знакомства с Мойрой: агент по порядку проходит четыре простых шага — понять задачу, выполнить её, проверить результат, отчитаться. Без развилок и без переменных. Запустите его с любой небольшой задачей, чтобы увидеть, как Мойра выдаёт агенту по одному шагу. Для настоящей работы опишите задачу своему агенту — он сам выберет готовый флоу или создаст новый.

## Шаги

- Прочитайте запрос пользователя и перескажите задачу одним предложением. Если что-то важное непонятно, спросите пользователя, прежде чем продолжать.
- Выполните задачу. Делайте только то, о чём просил пользователь, без лишней работы.
- Сравните результат с запросом. Если что-то не совпадает, исправьте это, прежде чем продолжать.
- Расскажите пользователю в нескольких предложениях, что вы сделали и как проверили.

## Как запустить

Проще всего попросить агента обычными словами, например:

> «Запусти пример Мойры „Пример 1: Простые шаги“ для этой задачи: …»

Агент, который вызывает инструменты напрямую, запускает его так:

```js
mcp__moira__start({ action: "prepare", workflowId: "moira/example-simple-steps-ru", parentExecutionId: "none" })
mcp__moira__start({ action: "execute", startAttemptId: "<Start attempt ID from prepare>" })
```

Это учебный пример. Для настоящей работы не нужно выбирать или собирать флоу: опишите задачу своему агенту — он сам выберет готовый флоу или создаст новый.

## Как это работает

<CardGrid>
  <Card title="Опишите задачу" icon="pencil">
    Скажите агенту обычными словами, что нужно. Разбираться, как устроены флоу, не обязательно.
  </Card>
  <Card title="Агент выберет флоу" icon="rocket">
    Он запустит подходящий готовый флоу или создаст новый под вашу задачу через Workflow Management
    Flow — простой или сложный, какой нужен задаче.
  </Card>
  <Card title="Каждый шаг проверяется" icon="approve-check">
    Moira выдаёт агенту по одной инструкции и проверяет подтверждение, прежде чем процесс пойдёт
    дальше, поэтому ничего не пропускается.
  </Card>
  <Card title="Заглянуть внутрь — по желанию" icon="open-book">
    Веб-приложение показывает любой флоу простыми пронумерованными шагами, картой процесса или
    полным графом. Всё это необязательно.
  </Card>
</CardGrid>

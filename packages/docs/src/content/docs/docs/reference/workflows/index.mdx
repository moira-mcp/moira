## Learning Examples

Three small flows for getting to know Moira: a straight sequence of steps, one fork, and a few paths. Each has an English and a Russian version. They are for learning; for real work, describe the task to your agent and it chooses a ready flow or creates one.

## Usage

Start any workflow:

```bash
mcp__moira__start({ action: "prepare", workflowId: "moira/quick-task", parentExecutionId: "none" })
mcp__moira__start({ action: "execute", startAttemptId: "<Start attempt ID from prepare>" })
```

List available workflows:

```bash
mcp__moira__list()
```

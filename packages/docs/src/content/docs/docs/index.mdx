## How it works

<CardGrid>
  <Card title="Describe the task" icon="pencil">
    Tell your agent what you need in plain words. You do not have to learn how flows are built.
  </Card>
  <Card title="The agent picks the flow" icon="rocket">
    It runs a ready flow that fits, or creates a new one for your task through the Workflow
    Management Flow — as simple or as complex as the task needs.
  </Card>
  <Card title="Every step is checked" icon="approve-check">
    Moira hands the agent one instruction at a time and validates its evidence before the process
    moves on, so nothing is skipped.
  </Card>
  <Card title="Look inside when you want" icon="open-book">
    The web app shows any flow as plain numbered steps, as a process map or as the full graph. All
    of it is optional.
  </Card>
</CardGrid>

title: Какой готовый флоу выбрать
description: Quick Task, Robust Task и Todo List для повседневных задач и когда вместо них попросить агента сделать новый флоу
---

Для большинства задач флоу выбирать не нужно: опишите задачу агенту, и он выберет сам. Эта
страница — если хочется понимать, из чего он выбирает, или назвать флоу самому. Три универсальных
флоу покрывают понятные задачи без особой логики; каждый запускается просьбой к агенту, например
«Запусти в Moira Quick Task для этого: …».

## Quick Task

`moira/quick-task` планирует работу, отдаёт план на проверку и утверждение, выполняет его по шагам
с подтверждениями, отдаёт результат на независимую проверку и просит вас его принять.

**Выбирайте, когда** задача понятная и ограниченная, это не изменение в репозитории кода и она
укладывается в план до десяти шагов: документ, исследование, набор правок, которые нужно
проверить. Нужен агент, который умеет писать файлы.

[Справка по Quick Task](/ru/docs/reference/workflows/quick-task/)

## Robust Task

`moira/robust-task` — та же идея для долгой или важной работы. Он хранит всё в долговременном
рабочем каталоге, поэтому запуск переживает прерывания; отправляет замечания ревью к шагу, который
их вызвал; перепланирует, когда новые факты меняют задачу; и честно сообщает о частичном
результате, вместо того чтобы назвать его готовым.

**Выбирайте, когда** задача большая или важная или по пути вероятны проблемы.

[Справка по Robust Task](/ru/docs/reference/workflows/robust-task/)

## Todo List

`moira/todo-list` проходит чек-лист по одному пункту — ваш или составленный один раз из вашей
цели, — прося короткое подтверждение, что пункт сделан, и позволяет поправить список по ходу. Ни
ревью плана, ни финального ревью в нём нет.

**Выбирайте, когда** шаги понятны и их нужно просто выполнить по порядку.

[Справка по Todo List](/ru/docs/reference/workflows/todo-list/)

## Что-то другое

- **Изменение в репозитории кода** — `moira/software-development-flow` планирует, реализует,
  тестирует, документирует и проверяет его. См. [справку по Software Development Flow](/ru/docs/reference/workflows/software-development-flow/).
- **Исследования, тексты, анализ и не только** — в [каталоге готовых воркфлоу](/ru/docs/reference/workflows/)
  есть все встроенные флоу; агент читает текущий список через `list()`, прежде чем выбрать.
- **Ничего не подходит** — попросите агента: «Создай в Moira флоу для …». Он соберёт его через
  Workflow Management Flow — простой или сложный, какой нужен задаче, — и им можно сразу
  пользоваться.

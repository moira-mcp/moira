3.  **Авторизуйте MCP сервер**

    Проверьте состояние подключения по инструкции выбранного клиента выше. Если Moira уже
    работает, сохраните это подключение. Иначе завершите поддерживаемый клиентом вход:
    браузерный OAuth, если он предложен, либо настройку API-токена в его родном формате.
    Сохранение конфигурации само по себе не подтверждает авторизацию.

    :::tip[OAuth не поддерживается?]
    Если ваш клиент не может открыть браузер для OAuth, создайте API-токен:
    1. Войдите в веб-интерфейс Moira → **Настройки → Приложения и токены → API-токены**
    2. Создайте токен и скопируйте его (начинается с `moira_`)
    3. Используйте пример токена выбранного клиента выше: расположение заголовка зависит от
       клиента, а Codex ссылается на переменную окружения. Не сохраняйте токен в Git или логах.

    Подробнее: [MCP клиенты → API-токены](/ru/docs/integration/mcp-clients/#api-токены)
    :::

4.  **Проверьте подключение**

    Попросите AI-клиент вывести список воркфлоу Moira:

    ```
    Покажи доступные воркфлоу Moira
    ```

    Вы должны увидеть список доступных воркфлоу.

5.  **Запустите первый флоу**

    Попросите агента обычными словами запустить первый учебный пример на любой небольшой задаче:

    ```
    Запусти в Moira Пример 1: Простые шаги для этой задачи: переименуй файл notes.txt в todo.txt
    ```

    Агент запускает `moira/example-simple-steps-ru` и проходит четыре шага — понять задачу,
    выполнить её, проверить результат, отчитаться — по одному; Moira выдаёт ему каждый шаг и
    проверяет ответ перед следующим. Откройте **Воркфлоу** в веб-приложении и выберите пример,
    чтобы увидеть те же шаги простой схемой.

    Дальше называть флоу вообще не обязательно. Опишите, что нужно, и агент сам выберет готовый
    флоу или соберёт новый под задачу. [Туториал](/ru/docs/getting-started/tutorial/) проходит все
    три учебных примера; [Какой готовый флоу выбрать](/ru/docs/getting-started/ready-flows/)
    рассказывает о повседневных.

    :::tip[Нужна экскурсия по каталогу?]
    Скажите `Запусти воркфлоу "user-onboarding" в Moira`. Интерактивный онбординг читает текущий
    доступный вам публичный каталог, объясняет, чем флоу различаются, фиксирует один точный
    воркфлоу, например `moira/test-planning`, и запускает его, только если вы так решите; отсрочка
    ничего не меняет.
    :::

## Доступные MCP-инструменты

Основной цикл выполнения использует следующие инструменты Moira:

| Инструмент                         | Описание                                                        |
| ---------------------------------- | --------------------------------------------------------------- |
| `workflow` (`list`)                | Получить доступные воркфлоу с пагинацией                        |
| `execution` (`prepare`, `execute`) | Подготовить или выполнить отдельный либо дочерний запуск        |
| `execution` (`step`)               | Отправить проверенный результат шага и получить новую директиву |
| `execution`                        | Просмотреть и возобновить выполнение воркфлоу                   |
| `help`                             | Получить документацию и справку Moira                           |

Moira также предоставляет операции управления workflow, настройками, заметками, артефактами,
блокировками, reconciliation и токенами больших файлов. Полный актуальный каталог, точные входные
схемы, поддерживаемые действия и примеры находятся в
[справочнике MCP-инструментов](/ru/docs/reference/tools/).

```
Moira: Start attempt ID: aaaaaaaa-aaaa-4aaa-8aaa-aaaaaaaaaaaa

Агент: [вызывает execution с action: "execute" и именно этим startAttemptId;
        при потере ответа повторяет execute, а не готовит новый запуск]

Moira: Process ID: 123e4567-e89b-42d3-a456-426614174000
       Step attempt ID: 11111111-1111-4111-8111-111111111111
       Ваша следующая задача: Проанализировать документ требований...
       Критерий успеха: Требования задокументированы...

Агент: [анализирует требования, создает вывод]

       Ваша следующая задача: Создать план реализации...

```

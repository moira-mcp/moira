Claude Code — официальный CLI и расширение VS Code для Claude от Anthropic. Это руководство описывает интеграцию Moira с Claude Code.

## Предварительные требования

- Установленный и настроенный Claude Code
- Доступ к серверу Moira (облако или self-hosted)
- Действующие учетные данные Moira

## Конфигурация

Используйте Claude Code в [MCP-клиентах](/ru/docs/integration/mcp-clients/): там находятся генерируемая настройка, её область действия, текущие способы авторизации и официальная инструкция поставщика. Сначала проверьте существующее подключение; если нужен вход, используйте его OAuth или родную альтернативу с API-токеном. Сохраните другие серверы и не копируйте учётные данные в инструкции проекта.

## Проверка подключения

Проверьте подключение, попросив Claude:

```
Покажи доступные воркфлоу Moira
```

Вы должны увидеть список ваших воркфлоу.

## Использование Moira в Claude Code

### Запуск воркфлоу

```
Найди актуальный workflow разработки в Moira и запусти его для этой задачи
```

Claude:

1. Вызовет `start` с `action: "prepare"` и ID воркфлоу
2. Вызовет `start` с `action: "execute"` и полученным Start attempt ID
3. Получит Process ID, Step attempt ID и директиву первого шага
4. Выполнит директиву
5. Отправит результаты через `step`
6. Продолжит до завершения воркфлоу

### Продолжение сессии

Если сессия была прервана, продолжите с:

```
Продолжи мой воркфлоу Moira с process ID abc-123
```

### Получение помощи

```
Покажи документацию Moira по узлам
```

Claude вызовет `help` с темой.

## Интеграция с CLAUDE.md

Для воркфлоу, специфичных для проекта, добавьте в `CLAUDE.md`:

```markdown
## Воркфлоу Moira

Этот проект использует Moira для воркфлоу разработки.

### Доступные воркфлоу

- `dev-flow` - Основной воркфлоу разработки
- `review-flow` - Воркфлоу код-ревью

### Начало разработки

Чтобы начать задачу, запустите воркфлоу разработки:

1. Подготовьте и выполните запуск воркфлоу `dev-flow`
2. Следуйте каждой директиве шага
3. Отправьте результаты перед переходом к следующему шагу
```

:::tip
Общие правила выбора workflow храните в CLAUDE.md. Активный Process ID сохраняйте в игнорируемом рабочем пространстве или handoff задачи, чтобы временное состояние запуска не стало постоянной инструкцией проекта.
:::

## Доступные инструменты

Основной цикл workflow использует следующие инструменты:

| Инструмент | Описание                                                  |
| ---------- | --------------------------------------------------------- |
| `list`     | Список доступных воркфлоу                                 |
| `start`    | Подготовка или выполнение защищённого от повторов запуска |
| `step`     | Отправка результата, получение следующей директивы        |
| `help`     | Получение документации                                    |
| `settings` | Управление пользовательскими настройками                  |
| `session`  | Информация о сессии и выполнениях                         |

Полный актуальный каталог, входные схемы, действия и примеры находятся в
[справочнике MCP-инструментов](/ru/docs/reference/tools/).

## Устранение неполадок

### Проблемы с подключением

1. Проверьте правильность URL MCP сервера
2. Проверьте сетевое подключение
3. Убедитесь в действительности аутентификации
4. Проверьте логи Claude Code на наличие ошибок

### Воркфлоу не запускается

1. Проверьте существование ID воркфлоу: `list`
2. Проверьте права доступа к воркфлоу
3. Убедитесь, что у вас есть доступ к воркфлоу

### Потеря сессии

Если process ID потерян:

1. Проверьте `session({ action: "executions" })` для активных выполнений
2. Возобновите с правильным process ID
3. Сохраните выбранный Process ID в игнорируемом workspace/handoff задачи

## Лучшие практики

1. **Сохраняйте Process ID** — Храните в игнорируемом workspace/handoff задачи
2. **Следуйте директивам** — Выполняйте именно то, что говорит директива
3. **Выполняйте условия завершения** — Проверяйте перед отправкой
4. **Проверяйте помощь** — Используйте `help` при неуверенности

---
title: Артефакты
description: Хостинг статического HTML для результатов workflow - отчёты, дашборды и визуализации с публичными URL
---

Артефакты обеспечивают хостинг статического HTML для результатов workflow. Загружайте HTML-контент (отчёты, дашборды, визуализации) и получайте публичные URL. JavaScript выполняется в sandbox-фрейме с панелью брендинга Moira. Размещение origin зависит от deployment; используйте возвращённый URL. Публичный артефакт не должен содержать credentials или конфиденциальные данные.

## Применение

- **Отчёты**: Генерация аналитических отчётов с доступом по URL
- **Дашборды**: Создание интерактивных HTML-дашбордов (JavaScript работает в странице)
- **Визуализации**: Хостинг графиков и визуализаций данных со встроенными в HTML
  данными (вызовы application API заблокированы)
- **Документация**: Публикация сгенерированной документации
- **Превью**: Демонстрация промежуточных результатов

## MCP Tool

MCP tool `artifacts` предоставляет следующие действия:

```json
artifacts({ action: "upload", name: "report.html", content: "<html>...</html>" })
artifacts({ action: "update", uuid: "abc-123", content: "<html>...</html>" })
artifacts({ action: "delete", uuid: "abc-123" })
artifacts({ action: "list", limit: 10 })
artifacts({ action: "stats" })
artifacts({ action: "token", ttlMinutes: 60 })
```

| Действие | Назначение                      |
| -------- | ------------------------------- |
| `upload` | Создать артефакт, получить URL  |
| `update` | Обновить содержимое артефакта   |
| `delete` | Удалить артефакт                |
| `list`   | Список артефактов с пагинацией  |
| `stats`  | Статистика использования квоты  |
| `token`  | Сгенерировать одноразовый токен |

### Upload

Создание нового HTML-артефакта. Артефакты доступны по адресу `https://{STATIC_DOMAIN}`.

```json
artifacts({
  action: "upload",
  name: "analysis-report.html",
  content: "<html><body><h1>Отчёт</h1></body></html>"
})
→ {
    uuid: "d0a925d6-7dd8-49ba-b90c-d03b43062d20",
    url: "https://d0a925d6-7dd8-49ba-b90c-d03b43062d20.{STATIC_DOMAIN}/",
    name: "analysis-report.html",
    size: 52,
    expiresAt: "2024-03-01T10:00:00Z"
  }
```

Опциональный `executionId` связывает артефакт с выполнением workflow.

### Update

Замена содержимого существующего артефакта:

```json
artifacts({
  action: "update",
  uuid: "d0a925d6-7dd8-49ba-b90c-d03b43062d20",
  content: "<html><body><h1>Обновлённый отчёт</h1></body></html>"
})
```

### List

Получение списка артефактов с пагинацией:

```json
artifacts({ action: "list", limit: 10, offset: 0 })
→ {
    artifacts: [{
      uuid: "d0a925d6-...",
      url: "https://d0a925d6-....{STATIC_DOMAIN}/",
      name: "report.html",
      size: 1024,
      createdAt: "2024-01-15T10:00:00Z"
    }],
    total: 5
  }
```

### Квоты и срок хранения

Политики хранилища, количества артефактов, размера файла и срока хранения задаются сервером и могут
иметь пользовательские переопределения. Эффективные квоты хранилища и количества возвращает
`stats`. Ошибки upload и update сообщают применённую границу размера файла, а значение `expiresAt`
в ответе является источником истины о сроке действия конкретного артефакта.

```json
artifacts({ action: "stats" })
→ {
    totalArtifacts: 5,
    totalSize: 51200,
    storageLimit: 104857600,
    countLimit: 50,
    storageUsedPercent: 0.05,
    countUsedPercent: 10
  }
```

## Токены загрузки

Генерация одноразовых токенов для HTTP API загрузки. Полезно для CI/CD пайплайнов или внешних инструментов, которые не могут использовать MCP напрямую.

```json
artifacts({ action: "token", ttlMinutes: 30 })
→ {
    token: "xyz-789",
    expiresAt: "2024-01-15T10:30:00Z",
    uploadUrl: "https://{MOIRA_HOST}/api/public/artifacts/upload/xyz-789"
  }
```

Загрузка через HTTP:

```bash
curl -X POST "https://{MOIRA_HOST}/api/public/artifacts/upload/xyz-789" \
  -H "Content-Type: application/json" \
  -d '{"name": "report.html", "content": "<html>...</html>"}'
```

Токены одноразовые и истекают после указанного TTL.

## Безопасность

Артефакты могут содержать JavaScript, поэтому каждый изолируется на нескольких уровнях:

- **Настроенный URL артефакта** — используйте `url` из результата upload или list. В deployment с
  отдельными поддоменами для каждого артефакта браузер изолирует storage, cookies и Service Workers
  между origin; точные host и path определяются конфигурацией deployment.
- **Песочница (sandbox)** — контент артефакта работает внутри
  `<iframe sandbox="allow-scripts">` (без `allow-same-origin`, без форм, без
  навигации верхнего уровня, без popup) на странице-обёртке под контролем
  Moira. Скрипты выполняются, но не могут добраться до обёртки.
- **Ограниченные соединения** — `connect-src 'none'` блокирует fetch/XHR/WebSocket/beacon;
  формы тоже заблокированы. При этом HTTPS-изображения и явно разрешённые script/style/font
  ресурсы могут загружаться. Это не гарантия отсутствия любых исходящих запросов или раскрытия
  данных: встраивайте данные визуализации и не публикуйте секреты.
- **Предупреждение при первом визите** — зрители видят промежуточный экран о
  том, что контент создан пользователем и не одобрен Moira, перед показом
  артефакта.

| Защита                 | Значение                                                                         |
| ---------------------- | -------------------------------------------------------------------------------- |
| CSP фрейма             | скрипты разрешены; `connect-src 'none'`, `form-action 'none'`, `base-uri 'none'` |
| Sandbox фрейма         | только `allow-scripts`                                                           |
| X-Content-Type-Options | `nosniff`                                                                        |
| Изоляция origin        | URL артефакта из конфигурации deployment                                         |

:::caution
JavaScript выполняется, но **соединения приложения ограничены** — `fetch`, `XHR` и `WebSocket` заблокированы.
Используйте артефакты для самодостаточного интерактивного контента (дашборды, калькуляторы,
визуализации со встроенными данными), а не для того, что должно обращаться к серверу.
:::

## Брендинг и жалобы

Каждый артефакт показывается на странице-обёртке с фиксированной нижней панелью:

- **Атрибуция** — ссылка «Created with Moira». Поскольку футер находится в
  обёртке (отдельный документ от артефакта), контент артефакта не может его
  перекрыть или удалить.
- **Жалоба** — ссылка «Report» позволяет зрителям пожаловаться на вредоносный
  контент для проверки. Уведомление администраторам использует их включённые и настроенные
  каналы связи. Оно выполняется best effort: отсутствие или отказ доставки не отменяют подачу жалобы.

Обёртка (предупреждение при первом открытии и футер) отображается на английском
или русском языке в зависимости от языка браузера зрителя, с переключателем
EN/RU в правом нижнем углу. Это касается только обёртки Moira, но не самого
контента артефакта.

Вредоносные артефакты могут быть заблокированы администраторами, после чего они
немедленно перестают обслуживаться.

## Интеграция с Workflow

### Паттерн Workspace

Используйте артефакты с паттерном workspace для организации результатов workflow:

```
./project-analysis/
├── step-1/
│   └── data-collection.md
├── step-2/
│   └── analysis.md
└── artifacts/
    ├── dashboard.html      # → загрузить как артефакт
    └── summary-report.html # → загрузить как артефакт
```

### Связь с Execution

Передайте `executionId` при загрузке для связи артефактов с выполнением workflow:

```json
artifacts({
  action: "upload",
  name: "execution-report.html",
  content: "...",
  executionId: "exec-abc-123"
})
```

Связанные артефакты отображаются в UI инспектора выполнений.

## Web UI

Артефакты управляются через веб-интерфейс на странице `/app/artifacts`:

- Просмотр артефактов с именем, размером, URL и датой истечения
- Загрузка новых артефактов с HTML-редактором
- Редактирование содержимого существующих артефактов
- Копирование публичного URL в буфер обмена
- Открытие артефактов в новой вкладке
- Удаление артефактов
- Мониторинг использования квоты с визуальным индикатором
